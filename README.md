# Data_companies_vacanсies

Функционал проекта следующий:
Происходит получение данных с сайта hh.ru о компаниях и вакансиях.
Создаются соответствующе таблицы в postgreSQL с загрузкой данных.  
Пользователю предоставляется возможность произвести предложенные выборки по вакансиям

## Разработка
Созданы основные модули
- headhunter_api - отправка и получение запроса от hh.ru
- utils - полученные данные формирует в фалы json
- database - чтение загруженных json файлов, создание БД, загрузка данных в БД
- DBManager - модуль для работы с пользовательскими запросами.
Получает список всех компаний и количество вакансий у каждой компании.
Получает список всех вакансий с указанием названия компании, 
          названия вакансии и зарплаты и ссылки на вакансию.
Получает среднюю зарплату по вакансиям.
Получает список всех вакансий, у которых зарплата выше средней по всем вакансиям.
Получает список всех вакансий, в названии которых содержатся переданные в метод слова.

Основной модуль main : 
При запуске сообщает о работающем функционале и загрузке данных
Так же предлагает пользователю выбрать предложенные выборки с выводом в консоли
